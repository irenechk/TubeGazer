# 🎬 TubeGazer

## 📖 Project Description

TubeGazer is a React.js-based Creator Intelligence Dashboard designed to help content creators manage and analyze their video content efficiently. The application provides tools for video analytics, copyright verification, retention tracking, upload optimization, and cross-platform content management through an interactive and modern user interface.

The project demonstrates the practical implementation of React concepts such as Hooks, Context API, Memoization, State Management, and Component-Based Architecture.

## ✨ Features

### 📊 Video Stats Dashboard

Displays video performance metrics, views, processing status, and content summaries.

### ⏪ Watch History Undo

Allows creators to revert accidental skips and restore previous watch positions.

### 🔀 Next Video Queue

Manages upcoming video recommendations with dynamic queue controls.

### 🛡️ Copyright Checker

Checks video content against licensed media assets and provides instant feedback.

### 📉 Viewer Retention Sorter

Ranks videos based on retention, engagement, and watch duration.

### ⚡ Quality Optimizer

Optimizes video segmentation and provides recommendations based on content length.

### 🌐 Cross-Platform Reach

Displays engagement statistics across multiple social media platforms.

### ⚠️ Video Processing Safety

Detects processing issues and provides fallback handling for corrupted video files.

### 🔐 Authentication System

Provides login, registration, and session persistence using localStorage.

## ⚙️ Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/irenechk/TubeGazer.git
```

### 2. Navigate to Project Directory

```bash
cd TubeGazer
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:5173
```

### 6. Build for Production

```bash
npm run build
```

### 7. Preview Production Build

```bash
npm run preview
```
